# maylan-antispam-bot

Бот-модератор для Telegram-группы с темами. Главное — порядок с картинками и гифками:

| Тема | Фото / видео | Гифки / стикеры |
|---|---|---|
| **Мемы** (`/setmemes`) | без ограничений | без ограничений |
| **Скриншоты и клипы** (`/setscreens`) | до 20 за 5 мин на человека | удаляются, подсказка «в мемы» |
| Остальные темы, включая General | до 3 медиа за 5 мин на человека (общий лимит) | |

Сверх лимита сообщение удаляется, а человек получает короткую подсказку со ссылкой на тему мемов (она сама исчезает через 15 секунд). Если человек трижды за час превышает лимит, он получает **медиа-бан** на 1 час: вне темы мемов его медиа сразу удаляются, а в мемах можно и дальше. Админов лимиты не касаются. Все числа меняются командами.

Ещё бот умеет: мут, бан, кик, предупреждения с автонаказанием, антифлуд, массовое удаление сообщений, режим «только чтение», жалобы админам, правила и лог действий в отдельный чат.

## Команды

Время указывается так: `30s`, `10m`, `2h`, `1d`, `1w`, `1h30m` (можно по-русски: `10м`, `2ч`, `1д`). Если указать просто число, это минуты. Цель команды выбирается ответом на сообщение или через `@username` / числовой ID.

**Для всех:** `/rules`, `/report` (ответом на сообщение), `/help`, `/id`.

**Модерация** (нужно право «Блокировка пользователей»):
- `/mute [время] [причина]` — мут (если время не указано, навсегда); `/unmute` — снять
- `/ban [время] [причина]`, `/unban`, `/kick`
- `/warn [причина]`, `/unwarn`, `/warns` — после 3 предупреждений мут на 1 день
- `/mediaban [время]`, `/mediaunban` — запрет на медиа вне темы мемов
- `/ro` — режим «только чтение» для всех, кроме админов; `/ro off` — выключить

У каждого наказания есть кнопка «Снять».

**Удаление** (нужно право «Удаление сообщений»): `/del` (ответом на сообщение), `/purge` (ответом: удаляет всё от этого сообщения до команды, максимум 1000).

**Настройки** (нужно право «Изменение профиля группы»):
- `/setmemes`, `/setscreens`, `/unsettopic` — отправлять внутри нужной темы
- `/setmedialimit 3 5m` — лимит в обычных темах
- `/setscreenlimit 20 5m` — лимит в теме скриншотов
- `/setstrikes 3 1h 1h` — 3 нарушения за час дают медиа-бан на час
- `/setflood 7 10s 10m`, `/antiflood on|off` — больше 7 сообщений за 10 секунд дают мут на 10 минут
- `/setwarnlimit 3 mute 1d` (или `ban 7d`)
- `/setlog <ID чата>` / `/setlog off` — куда писать лог (ID можно узнать командой `/id` в этом чате)
- `/setrules <текст>`, `/settings`

## Настройка бота в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и сохраните токен.
2. В @BotFather: `/setprivacy` → выберите бота → **Disable**. Без этого бот не видит обычные сообщения и картинки.
3. Добавьте бота в группу и сделайте админом с правами **«Удаление сообщений»** и **«Блокировка пользователей»**.
4. Зайдите в тему мемов и отправьте `/setmemes`, затем в тему скриншотов — `/setscreens`.

## Развёртывание на Vercel

Бот работает через webhook: Telegram присылает каждое сообщение на `https://<проект>.vercel.app/api/bot`. Данные (настройки, счётчики, предупреждения) хранятся в Upstash Redis: на Vercel нет постоянного диска.

1. Залейте репозиторий на GitHub и импортируйте его в [Vercel](https://vercel.com/new). Ничего настраивать для сборки не нужно.
2. В проекте на Vercel откройте **Storage → Marketplace → Upstash → Redis**, создайте базу на бесплатном тарифе и подключите её к проекту. Переменные подключения проставятся сами.
3. В **Settings → Environment Variables** добавьте:
   - `BOT_TOKEN` — токен от BotFather;
   - `WEBHOOK_SECRET` — любая длинная случайная строка из латиницы, цифр, `_` и `-`.
4. Сделайте Redeploy, чтобы переменные применились.
5. Локально создайте `.env` по образцу `.env.example` (нужны `BOT_TOKEN`, `WEBHOOK_SECRET` и `WEBHOOK_URL`) и выполните:
   ```bash
   npm install
   npm run set-webhook
   ```
   Скрипт зарегистрирует webhook и меню команд.

Проверить состояние webhook можно так: `https://api.telegram.org/bot<токен>/getWebhookInfo`.

## Локальный запуск

```bash
npm install
cp .env.example .env   # впишите BOT_TOKEN
npm run dev
```

Локально бот работает через long polling и при старте сам снимает webhook. Поэтому после локальных экспериментов снова выполните `npm run set-webhook`. Если Upstash в `.env` не указан, данные хранятся в памяти и пропадают при перезапуске.

## Разработка

```bash
npm test           # юнит-тесты и прогон бота с подменённым Telegram API
npm run typecheck
```

Структура: `api/bot.ts` — функция Vercel; `src/bot.ts` — сборка бота; `src/modules/` — правила медиа, антифлуд, команды; `src/store.ts` — хранилище (Redis или память).

## Ограничения

- Бот узнаёт пользователя по `@username`, только если уже видел его сообщения. Иначе ответьте на сообщение пользователя или укажите числовой ID (его покажет `/id` ответом на сообщение).
- `/ro` работает без таймера, выключается только командой `/ro off`: на serverless нет фоновых задач.
- Медиа-бан действует на стороне бота, а не через права Telegram. Права Telegram применяются сразу ко всей группе и закрыли бы и тему мемов.
- `/purge` удаляет сообщения по диапазону ID. В группе с темами диапазон захватывает сообщения из всех тем.
